# Requisito
Descrizione dei meccanismi coerente con il codice (Morris 2019, §3.2)[^morris2019]

# Esito dell'audit iniziale
Non conforme. §2.2 dice che GLMM-native ha coefficienti condizionali 'calibrated per replicate': nel codice sono costanti fisse (-2.32, 0.116, 0.232... = 1,16 x marginale, approssimazione di Zeger con D=1). La calibrazione per replicato e' quella di GLMM-AR1 (calibrate_beta_c_ar1). Inoltre per M5 AR1 usa D[3,3]=0.01 e GLMM-native 0.001, quindi 'mirrors R_manual exactly' e la generalizzazione stretta (§2.2, [V-05](../../verification/V-05.md)) non valgono per M5.

# Azione
Correggere §2.2; allineare D di M5 o dichiararne la differenza.
