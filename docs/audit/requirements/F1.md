# Requisito
n_sim giustificato (Morris 2019, §5.3, §6.1)[^morris2019]

# Esito dell'audit iniziale
Non conforme. n_sim=1000 fissato senza giustificazione. MCSE per cella dell'errore di I tipo al 5% = 0,69 pp (0,98 con 50% di fit usabili); per livello di N, aggregando le celle, 0,12-0,31 pp (tables/G_level_fixed.csv). Per MCSE=0,5 pp per cella servirebbero 1.900 replicati.

# Azione
Dichiarare la MCSE attesa che ha motivato n_sim e le differenze che il disegno puo' risolvere.
