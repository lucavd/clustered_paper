# Requisito
Specifiche dei metodi e versioni del software (Morris 2019, §3.4, §4.3)[^morris2019]

# Esito dell'audit iniziale
Parziale. Le versioni sono rinviate a un supplemento che appartiene a una versione precedente. renv.lock non contiene geesmv e indica R 4.5.2, mentre il run e' stato eseguito su R 4.6 (run_full.R). Non dichiarati: Laplace (nAGQ=1); ottimizzatore di default per il Wald e bobyqa per il LRT; q=20 per MMM; scale.fix=TRUE; timeout rigido di 5 s per geesmv, conteggiato come fallimento (fino al 16,8% in una cella, tables/geesmv_timeouts.csv).

# Azione
Riportare nel testo sessionInfo del run e le opzioni di stima, incluso il timeout.
