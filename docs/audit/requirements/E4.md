# Requisito
MCSE delle misure complesse (Morris 2019, §5.2)[^morris2019]

# Esito dell'audit iniziale
Parziale. Bootstrap disponibile per il worst case e per le celle vinte. Manca l'incertezza per la potenza size-adjusted, il rango combinato (§4.1), il ranking per T e le correlazioni di Spearman.

# Azione
Jackknife o bootstrap per replicato (Boos & Osborne).
