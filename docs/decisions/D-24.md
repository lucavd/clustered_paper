# Decisione

Opzione (a) di [inferenza per blocchi (S5)](../steps/S5.md): i replicati restano 1.000 per cella in tutte le celle. Il ramo (b) di [Replicati per cella: restano 1.000 (D-03)](D-03.md), aggiungere replicati dove una conclusione poggia su una differenza entro 2 MCSE, non scatta. Le 17 sotto-affermazioni con rilevanza indeterminata (intervallo sopra 0 ma a cavallo del margine) si scrivono nel testo come differenze di "circa un punto" (o del margine della loro misura), senza affermare che superino il margine.

# Motivazione

Con il bootstrap per blocchi nessuna delle 149 sotto-affermazioni calcolate e' *non risolta* ([V-53](../verification/V-53.md)).[^matrice] Per risolvere le indeterminate servirebbero fino a circa 40.000 replicati per cella, oltre 500.000 in un caso ([V-61](../verification/V-61.md)), per sapere soltanto se una differenza di circa 1 punto supera 1,00. Scelta del PI in chat il 2026-10-18, sulla raccomandazione dello step.[^step]
