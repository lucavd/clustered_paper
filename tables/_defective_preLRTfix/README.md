# Defective tables — do not cite

These were aggregated with a Wald standard-error filter applied uniformly to every
method. A likelihood-ratio p-value comes from a deviance difference and never uses
that standard error, so the filter discarded valid results for `glmer_lrt` only:
113,791 of 1,435,382 finite rows (7.93%). Because separated replicates are the ones
most likely to reject, the exclusion understates that method's rejection rate.

Superseded by `../F_*.csv` and `../P_*.csv`, which apply a per-method filter.
Kept for provenance: the earlier manuscript numbers came from here.
