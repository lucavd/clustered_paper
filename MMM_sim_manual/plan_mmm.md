# MMM_sim_manual — Independent Data Generating Process for MMM Simulation

## Objective

Create a **GLMM-native data generating process (DGP)** that is completely independent
of the MMLB package. This eliminates the legitimate criticism that data generated by
`MMLB::GenBinaryY` inherently favors MMM, since GenBinaryY IS the MMM model.

If MMM still performs well on data generated from a standard GLMM, the argument
that MMM is robust and reliable becomes much stronger.

---

## Why GenBinaryY Favors MMM

`GenBinaryY` generates data as follows:

1. Takes **marginal** parameters β_m as input
2. Converts β_m → conditional δ via `Etai2Deltai()` (GH deconvolution)
3. Draws subject-specific z_i ~ N(0,1)
4. Generates Y sequentially: P(Y_it=1) = expit(δ_it + σ_it·z_i + γ_it·Y_{i,t-1})

This is **exactly** the MMM model. Three sources of bias:

- **Parameterization bias**: true parameters are marginal → MMM targets them directly
- **Model structure bias**: the DGP has both random effects AND AR(1) transition →
  a simple GLMM with (1|id) is misspecified (ignores transition)
- **Software coupling**: the same package generates and fits the data

## GLMM-Native DGP Design

### Core model

Standard Generalized Linear Mixed Model:

```
logit(P(Y_ij = 1 | b_i)) = X_ij' β_c + Z_ij' b_i
b_i ~ N(0, D)
Y_ij | b_i ~ indep Bernoulli(expit(X_ij' β_c + Z_ij' b_i))
```

Key differences from GenBinaryY:
- **Conditional parameterization**: β_c are subject-specific (conditional) coefficients
- **No transition/AR structure**: observations are conditionally independent given b_i
- **No MMLB dependency**: pure base-R + MASS::mvrnorm for random effects

### True marginal parameters

For fair evaluation, we compute the true marginal parameters that MMM/GEE target.

**Zeger approximation** (for random intercept, D = σ²):
```
β_m ≈ β_c / sqrt(1 + c² · σ²)
where c = 16√3 / (15π) ≈ 0.5877
```

**Exact via Gauss-Hermite quadrature** (for random intercept):
```
P(Y=1 | X) = Σ_k w_k · expit(X'β_c + √σ² · z_k)
```
where (z_k, w_k) are GH nodes/weights for N(0,1).

For random slopes, the effective variance is observation-specific:
```
Var(Z_ij' b_i) = Z_ij' D Z_ij
```
and the Zeger approximation uses this local variance.

### Evaluation strategy

Each method is evaluated against its **appropriate** ground truth:
- **GLMM**: compare to true β_c (conditional parameters)
- **MMM, GEE**: compare to true β_m (marginal parameters, computed via GH)
- **Shrinkage GLM**: compare to true β_m

Under the null (β_c = 0 for some terms): β_m = 0 too → Type I error is
the same regardless of parameterization.

## Five Models (Analogous to Current Simulation)

| Model | Fixed effects      | Random effects         | MMLB analog         |
|-------|--------------------|------------------------|----------------------|
| M1    | time*trt           | (1\|id)                | lv=~1, t=~1         |
| M2    | time*trt + age     | (1\|id)                | lv=~1, t=~1         |
| M3    | time*trt           | (1 + age\|id)          | lv=~age, t=~1       |
| M4    | time*trt           | (1 + age\|id)          | lv=~age, t=~trt     |
| M5    | time*trt           | (1 + age + sex\|id)    | lv=~age+sex, t=~trt+steroids |

Note: Models 3/4 differ in MMLB (M4 has transition on trt) but are identical in
the GLMM DGP since GLMM has no transition structure. This is intentional — it
tests whether MMM handles "extra" model components robustly.

### Parameter values

**Alternative hypothesis** (for power/MAPE evaluation):

| Model | β_c (conditional)              | D                        |
|-------|-------------------------------|--------------------------|
| M1    | (-2.3, 0.12, 0.23, 0.23)     | 1.0                      |
| M2    | (-2.3, 0.12, 0.23, 0.23, 0.01) | 1.0                   |
| M3    | (-2.3, 0.12, 0.23, 0.23)     | [[1.0, 0.01], [0.01, 0.001]] |
| M4    | (-2.3, 0.23, 0.23, 0.06)     | [[1.0, 0.01], [0.01, 0.001]] |
| M5    | (-2.3, 0.12, 0.23, 0.23)     | [[1.0, 0.01, 0.01], [0.01, 0.001, 0], [0.01, 0, 0.01]] |

Approximate marginal equivalents (via Zeger with D[1,1]=1):
shrinkage ≈ 1/1.16, so β_m ≈ β_c/1.16 ≈ (-1.98, 0.103, 0.198, 0.198)
→ close to current MMLB values: (-2, 0.1, 0.2, 0.2)

**Null hypothesis** (for Type I error):
β_c = (β_c0, 0, 0, 0) — only intercept nonzero, all slopes zero.
β_c0 chosen to give ~50% prevalence marginally → β_c0 = 0.

### Dropout mechanism

Same as current simulation:
- 70% of patients: full ntime observations
- 30% of patients: truncated (random 1 to ntime-1 observations)

## Validation Tests

1. **Marginal prevalence**: generate 10,000 datasets, check empirical prevalence
   matches theoretical E[expit(X'β_c + b)]
2. **ICC**: compute empirical ICC and compare to theoretical D/(D + π²/3)
3. **Conditional parameter recovery**: fit GLMM to generated data, check that
   estimated β_c_hat ≈ true β_c (unbiased, coverage ~95%)
4. **Marginal parameter recovery**: fit GEE to generated data, check that
   estimated β_m_hat ≈ computed true β_m
5. **No MMLB dependency**: verify the function runs without MMLB loaded
6. **Reproducibility**: same sim_id → same data
