# Port of the v6 submission text into the Quarto sources

Inputs: MMM_v5.qmd, MMM_v5_supplement.qmd (current sources), V5_S7f_numbers.csv (registry, 3,150 ids), MMM_v6_SMMR_manuscript_anonymized.docx, MMM_v6_SMMR_supplement_anonymized.docx, MMM_v6_registro_modifiche.md. Work done locally only (pandoc 3.12.1 in the sandbox); no server, no git.

Outputs: the edited MMM_v5.qmd and MMM_v5_supplement.qmd (same filenames), port_v6_literals.csv, port_v6_token_diff.csv.

## Result in one paragraph

After emulated rendering (tokens replaced by registry text with the -0 rule, setup chunk, YAML and HTML comments dropped), the edited main text matches v6 in 469 of 483 units and the supplement in 801 of 809 units. All 22 remaining differences are equation markup: the docx stores formulas as OMML, and pandoc reads them back as TeX with different braces and spacing. After canonicalising the math, both documents are identical to v6. Italics and bold match v6 exactly (same multiset of emphasised strings in both files), no code spans remain, no token id was invented, and the only ids removed are the three of the anonymised Code and data availability paragraph.

## Gate

Method. Each source was emulated: YAML header and R setup chunk dropped, HTML comments dropped, every `r n("<id>")` replaced by the registry column text (a text such as -0 or -0.0 printed without the minus). The emulator was first checked against the supplied v5 renders: block by block identical for main (175 blocks) and supplement (587 blocks), apart from the YAML title heading that the render prints. Emulated sources and v6 docx files were parsed by pandoc into an AST; paragraphs, headings, list items (references) and table rows became comparable units; paragraphs were split into sentences. Normalisation: whitespace, non-breaking spaces, curly quotes, en/em dashes and minus signs, italics/bold/code markup, link markup, and markdown pipe tables vs docx tables (one unit per row, cells joined by " | "). The sequences were aligned with difflib.

| document | units in v6 | units in source | identical | non-identical | non-identical after math canonicalisation |
|---|---|---|---|---|---|
| main | 483 (357 sentences, 54 table rows, 40 list items, 32 headings) | 483 | 469 | 14 | 0 |
| supplement | 809 (302 sentences, 489 table rows, 18 headings) | 809 | 801 | 8 | 0 |

Additional checks:
- Document titles: main YAML title equals the v6 docx Title paragraph; supplement YAML title equals it after the port above.
- Emphasis: multiset of italic strings and of bold strings identical to v6 in both files; no inline code remains outside tokens.
- HTML comments: same sequence of claim/noclaim comments (84 main, 42 supplement), each still after the same sentence; the only differences in the preceding sentence are the v6 edits of that sentence (abstract, two table numbers, two citation numbers in the main text; two table numbers in the supplement).
- Token uses: main 548 before, 570 after (+25 in Table 2, -3 in Code and data availability). Token ids: every id of the original supplement still present (no change). Main: all ids still present except f:x|git_commit, f:sw|fewclust, f:sw|fewclust_commit (sentence removed by v6, see port_v6_token_diff.csv). Ids used: all exist in the registry (0 invented).
- Rendering with Quarto/R was not run (no R registry environment and no server access by design); the emulator is the gate.
